# Дизайн

`prototypes/` — **рабочие отчёты, которые сейчас используются** (сохранены как HTML с данными). Это макеты новых страниц: структура вкладок, колонки таблиц, подсказки, цвета и состояния должны совпасть.

| Файл | Страница в Nuxt |
|---|---|
| `prototypes/sprints.html` | `/sprints` (все вкладки) |
| `prototypes/attendance.html` | `/attendance` |
| `prototypes/employee.html` | `/employee/:id` |
| `prototypes/snapshot.html` | `/snapshots/:date` |

Открывать прямо в браузере — всё внутри файла.

## Токены (взяты из прототипов)
- Шрифт: системный `-apple-system, Segoe UI, Roboto, sans-serif`, 14 px, таблицы 13 px, `font-variant-numeric: tabular-nums` для чисел.
- Светлая и тёмная тема через CSS-переменные `--bg --fg --sub --line --card --accent` (см. `:root` в прототипах); в Nuxt — Tailwind `darkMode: 'media'` + те же переменные.
- Статусы-«пилюли»: `ok` (зелёный), `warn` (жёлтый), `bad` (красный), `mute` (серый).
- Цвета статусов задач: todo — серый, в работе — синий, ревью — фиолетовый, реворк — оранжевый, тест — бирюзовый, готово — зелёный. Одинаковые во всех графиках.

## Правила UI
- Каждое число в таблице — ссылка в Jira с готовым JQL (как в прототипах: `cf[10104]`, `status`, `assignee`).
- Подсказка (`title`) у каждого заголовка колонки — текст из прототипа.
- Фильтр по руководителю сверху и общий для всех вкладок; сохраняется в query-строке.
- Таблицы сортируются по клику; ширина — без горизонтального скролла на 1280 px, на телефоне карточки.
- Посещаемость и карточка сотрудника — помечены «Доступ только у руководителей».

## Компоненты Nuxt (предложение)
`AppHeader`, `LeadFilter`, `KpiRow`, `DataTable` (сортировка, подсказки, ссылки в Jira), `StatusBar` (полоса статусов спринта), `SprintBurn` (echarts, ряд `sprint_daily`), `Pill`, `PersonChip`, `DayGrid` (клетки по дням для посещаемости), `EmptyState`.
