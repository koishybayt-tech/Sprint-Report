Заблокированные задачи

Кто кого ждёт: фронт ждёт связанные задачи дизайна и бэка, бэк (и ИИ) ждёт только дизайн, дизайн никого не ждёт. Задачи берутся по связям в Jira. «Ждёт задачу» — первая блокирующая задача, ещё не дошедшая до теста (сначала бэк, потом дизайн); красным — она даже не начата. Если все блокирующие задачи уже на тесте или дальше — «Можно снимать блок» с датой, когда последняя из них ушла на тест.

Задачи, которые долго в работе

«В работе», Code review и Need Rework. Дни в статусе — с последнего перехода в него по истории Jira; «с начала» — с первого перехода в «В работе». Красным — от 10 дн., оранжевым — от 5.

Сотрудники: задачи руководителя стоят, а у другого руководителя двигаются

Считаются действия самого сотрудника по истории Jira: «взял» — перевёл задачу в «В работе», «завершил» — перевёл в Code review, Test или дальше. «Тормозит» — у него есть задачи этого руководителя в «Сделать», «В работе» или Need Rework без смены статуса ≥ 3 дн., а за последние 7 дней он брал и завершал задачи других руководителей чаще, чем делал что-то по задачам этого руководителя. Тестировщики и ПМ не помечаются.

Дизайн или бэк готов, а продолжения нет

Только задачи текущего спринта. Плитка показывает число строк этой таблицы; по клику на плитку фильтры сбрасываются. Приоритет: «Высокий» — нет задачи на фронт; «Проверить» — найдена только похожая задача или бэк готов без фронта; «Низкий» — дизайн без бэка, дизайн-задачи без разработки, исправления ошибок.

Пара ищется по связи Relate, по одинаковому названию после «Дизайн -» / «Фронт -» / «БЭК -» и по похожему названию («похоже N%» — проверить вручную). Готовый фронт без бэка проблемой не считается.

Задачи, которые долго на тесте

Тестировщик — из поля «Тестировщик» в Jira (в части задач там стоит значение по умолчанию). Дни с последнего перехода в Test. Красным — от 7 дн., оранжевым — от 3.
